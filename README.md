# Aleen Clothing — Official Website

Consciously Curated Haute Couture & Heritage Garments.

## Pages:
- `index.html` — Main Editorial Landing Experience
- `collections.html` — Full Garments Gallery with live filtering and quick-examine
- `coord-sets.html` — Contemporary Co-ord Sets
- `dresses.html` — Haute Dresses & Sets Edit
- `admin.html` — 1-Page E-Commerce Garment Management Dashboard (Access via lock icon in footer, password: `aleen`)

## Running the Website:
```bash
cd "Aleen website"
npm start
# Opens at http://localhost:3300
```
